8) User Flow Overlay — 7 Steps

Prototype jalur (lihat prototype interaktif):
1) Entry → List (shell + toolbar) — debounce 300ms → filtered
2) Refresh → refetch tanpa reset (search/sort/page dipertahankan)
3) Empty → NEmpty+CTA “Buat Data Pertama” → create modal (bukan fondasi, tapi CTA ada)
4) Error → NAlert+Retry → refetch → success toast — ERR-01
5) 403 → floating global Akses Ditolak (1 instance) — ERR-02 / AC-D03
6) Collapse 220↔72 → navigate /data/:table, /run/:id, /documents/:id → highlight benar — Step 5 / AC-D04
7) Dashboard per peran (designer/operator/empty) → shortcut dinamis via /api/navigation — Step 6
8) Login fail → inline NFormItem+ NAlert “Email atau password salah” → success → redirect dashboard — Step 7 / AC-D04
