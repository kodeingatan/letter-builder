## Keputusan Design 28 (untuk Task 29)

- **Reorder**: kontrol eksplisit `ChevronUp`/`ChevronDown` (bukan drag palsu, bukan drag-and-drop sungguhan) — persist per-klik debounce + live region `Dipindahkan ke posisi ${pos}`. Alasan: a11y, konsisten dengan `GlobalTableTable.vue:58-68`, hindari kompleksitas DnD.
- **CSV preview limit**: 5 baris preview + 20 baris error table di modal; file >5MB atau >5000 baris ditolak dengan 422 `File terlalu besar` / `Maks 5000 baris` (server `table-data.service.ts:210` + `_token-diff` 5000 limit). Alasan: menjaga performa, konsisten server.
- **Richtext & expr baru**: placeholder konsisten (richtext → `NInput textarea 4 rows` + note `Editor penuh di Task 35`; expr test hanya existing `++` + aritmetika `IF/SUM` ditandai `Task 37`). Tidak ada deviasi scope.
- **Token audit**: 0 off-token — `purple`→`warning`, `#666`→`#94a3b8`, `text-blue-500`→`NButton primary ghost`, `#6366f1` tidak ada. Icons semua `h(NIcon, null, {default:()=>h(Icon)})`. Radius 6/4/8, Inter, spacing Tailwind, motion Fast150/Normal250/Slow350 + `prefers-reduced-motion`.
