# Responsive Design

## Breakpoints

```
sm: 640px    — Mobile landscape
md: 768px    — Tablet
lg: 1024px   — Desktop
xl: 1280px   — Wide desktop
2xl: 1536px  — Ultra wide
```

## Desktop (lg+)

- Full workspace layout
- Sidebar + Canvas + Properties panel visible
- Dense information layout
- Keyboard shortcuts active

## Tablet (md-lg)

- Sidebar collapsible
- Canvas full width
- Properties as overlay/drawer
- Touch-friendly tap targets

## Mobile (< md)

- Single column layout
- Navigation via bottom tabs or hamburger
- Full-screen panels
- Focused workflow (no split view)
- Simplified builders

## Responsive Tables

- Desktop: full table with all columns
- Tablet: horizontal scroll
- Mobile: card layout or simplified view

## Responsive Forms

- Desktop: multi-column forms
- Tablet: 2-column forms
- Mobile: single-column forms

## Navigation Behavior

```
Desktop:  Persistent sidebar
Tablet:   Collapsible sidebar
Mobile:   Bottom navigation or drawer
```
