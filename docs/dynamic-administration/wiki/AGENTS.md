# BMS Wiki Schema

## Overview

Knowledge base for the **Dynamic Administration & Document Composition Platform** (BMS).
Covers data modeling, component system, template composition, administration workflows, and document rendering.

## Article Structure

Each article covers one core concept. Articles use `[[wikilinks]]` to reference related concepts.

## Categories

- **Platform Architecture** — High-level system overview and flow
- **Data Layer** — Global tables, columns, relations, CRUD generation
- **Expression Engine** — Computed fields, expressions, unified data language
- **Component System** — Reusable document blocks, data requirements, looping
- **Template System** — Document composition, binding, rich text editing
- **Administration System** — Workflows, steps, multi-template processes
- **Rendering** — Document rendering engine, runtime flow
- **UI Generation** — Auto-generated menus from metadata
- **Architecture Principles** — Design rules and patterns
- **Referensi & Core Concept** — Statamic adaptation map, perfected core concept, v2 column catalog, runtime administration

## Conventions

- Article names match section headings from the source document
- Wikilinks use `[[article-name]]` format (kebab-case)
- Each article has: heading, content, and relevant wikilinks
- Cross-references are bidirectional when concepts are mutually dependent
