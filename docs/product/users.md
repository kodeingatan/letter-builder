# Users

## User Types

### Administrator

**Role:** System configurator and data architect

**Responsibilities:**
- Define Global Tables (data structures)
- Create and manage columns/fields
- Build reusable document components
- Design document templates
- Configure administration workflows
- Manage step sequences and data binding

**Goals:**
- Create flexible data structures without coding
- Build document templates that can be reused
- Configure workflows that guide staff through document creation

**Permissions:**
- Full access to Collections (Global Tables)
- Full access to Components
- Full access to Templates
- Full access to Workflows (Administrations)
- Can publish/unpublish resources

### Staff

**Role:** Document creator

**Responsibilities:**
- Follow administration workflows to create documents
- Fill in required data at each step
- Select data from Global Tables when prompted
- Preview and generate final documents

**Goals:**
- Create documents quickly and accurately
- Follow standardized processes
- Generate PDF output

**Permissions:**
- Can use published Workflows
- Can read Global Table data
- Cannot modify data structures
- Cannot modify templates or components

### Manager

**Role:** Reviewer and approver

**Responsibilities:**
- Review generated documents
- Approve or reject documents
- Monitor document generation activity

**Goals:**
- Ensure document accuracy
- Maintain quality standards

**Permissions:**
- Can view generated documents
- Can approve/reject documents
- Read-only access to data
