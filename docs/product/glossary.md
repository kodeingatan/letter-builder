# Glossary

| Term | Definition |
|------|-----------|
| **Global Table** | A metadata-driven data structure defined by users, providing automatic CRUD operations |
| **Column / Field** | A field definition within a Global Table specifying type, behavior, and UI |
| **Component** | A reusable document block with declared data requirements but no embedded data |
| **Data Requirement** | A contract specifying what data a Component needs |
| **Template** | A document blueprint assembling static content, components, bindings, loops, and conditions |
| **Data Binding** | A connection between a Component requirement and a data source |
| **Administration** | A multi-step workflow guiding document creation |
| **Step** | A single data gathering stage within an Administration |
| **Document** | A generated output (HTML/PDF) from executing a workflow |
| **Expression Engine** | A computation system evaluating math/string expressions with field references |
| **Computed Field** | A field whose value is calculated from other fields via expression |
| **Render Engine** | The system that resolves templates, bindings, loops, and conditions into final output |
| **Collection** | UI term for Global Table (user-facing) |
| **Field** | UI term for Column (user-facing) |
| **Document Component** | UI term for Component (user-facing) |
| **Document Template** | UI term for Template (user-facing) |
| **Document Workflow** | UI term for Administration (user-facing) |
| **Workflow Step** | UI term for Step (user-facing) |
| **Document Composition Canvas** | The rich text editor used to build Templates and Components |
| **Dynamic Token** | A `{{variable}}` placeholder in component/template content |
| **Repeat / Loop** | A component mode that renders once per item in a collection |
| **Conditional Block** | A template section rendered only when a condition is true |
| **Version** | A snapshot of a Template or Component at a point in time |
| **Published** | A resource status indicating it is available for use |
| **Draft** | A resource status indicating it is still being edited |
| **Archived** | A resource status indicating it is no longer active |
