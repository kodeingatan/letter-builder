# Definition of Done

A feature is considered **DONE** only when ALL of the following conditions are met.

## Specification

- [ ] requirements.md complete
- [ ] domain.md complete
- [ ] business-rules.md complete
- [ ] api.md complete
- [ ] ui.md complete
- [ ] ux.md complete
- [ ] acceptance.md complete
- [ ] test-cases.md complete
- [ ] tasks.md complete
- [ ] Specification reviewed and approved

## Implementation

- [ ] All tasks in tasks.md completed
- [ ] Database schema created/migrated
- [ ] Backend services implemented
- [ ] API routes implemented
- [ ] Frontend composable implemented
- [ ] UI components implemented
- [ ] Pages implemented
- [ ] Validation implemented (server + client)
- [ ] Error handling implemented
- [ ] All states handled (loading, empty, error, success)

## Verification

- [ ] Typecheck: PASS
- [ ] Lint: PASS
- [ ] Unit tests: PASS
- [ ] Integration tests: PASS
- [ ] Build: PASS
- [ ] API verification: PASS
- [ ] UI verification: PASS
- [ ] Accessibility: PASS

## Acceptance Criteria

- [ ] All acceptance criteria in acceptance.md: PASS
- [ ] Evidence provided for each criterion

## UI/UX

- [ ] Loading state implemented
- [ ] Empty state implemented
- [ ] Error state implemented
- [ ] Success feedback implemented
- [ ] Validation feedback implemented
- [ ] Responsive design verified
- [ ] Keyboard navigation verified
- [ ] Design system followed

## Review

- [ ] Architecture reviewed: PASS
- [ ] Backend reviewed: PASS
- [ ] Frontend reviewed: PASS
- [ ] UI/UX reviewed: PASS
- [ ] Security reviewed: PASS
- [ ] Performance reviewed: PASS
- [ ] No CRITICAL findings
- [ ] No HIGH findings

## Final Check

**ALL checkboxes above must be checked.**

If any checkbox is unchecked, the feature is NOT done.
