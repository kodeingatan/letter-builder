## Objective

Menghasilkan **wireframe low-fi, mockup hi-fi, dan prototype interaktif (Storybook)** untuk **Letter Builder Polish** — penyempurnaan menyeluruh lanjutan dari `08-letter-builder-ux-improvement-ui-design` (FASE 1 DONE) + `09-letter-builder-ux-improvement` (FASE 2 DONE) — dengan fokus **7 poin user**:

1. **Dedicated pages untuk semua create & update** (migrasi dari `NModal`/`NDrawer` ke route baru ber-layout sama via `PageShell`), 2. **Fix crash Tiptap `Cannot read properties of undefined (reading 'configure')` pada `ComponentEditor.vue` create & delete** (extension init guard + `ClientOnly` + lazy import audit), 3. **Polish Builder di `/dashboard/templates/:id`** (route `templates/[id].vue`) menjadi lebih cantik & mudah (3-pane `260|1fr|320` ditata ulang, EmptyStateCard, toolbar pill, canvas warm), 4. **Fix `DR-002` Administrasi Mapping incomplete — `missing: field`** (form mapping dibuat eksplisit per-template requirement dengan validasi inline yang mudah dipahami), 5. **Global UI/UX polish** agar semua halaman surat lebih mudah dipakai user awam, 6. **Manfaatkan Tiptap maksimal** merujuk `https://tiptap.dev/docs/examples` — toolbar office-doc minimal tetapi lengkap (bold/italic/underline/strike, heading, list, align, table, image, link, color/highlight, history, placeholder, bubble menu), 7. **Playwright video `https://playwright.dev/docs/videos#record-video`** — setiap pengujian merekam video (`video: 'on'`/`retain-on-failure`, `context.tracing`, `size`, `mode`).

Deliverables menjadi **acuan pixel-perfect FASE 2** `tasks/11-letter-builder-polish/` (Implementation: routing, service/DTO tidak berubah, hanya wiring + Tiptap hardened + video config + tests).

## Context

Roadmap `05 (Document Engine) → 06 (Master Data DDL) → 07 (Template & Administrasi) → 08 (UX Improvement UI Design) → 09 (UX Improvement Implementation: 409 hardening)` telah **DONE + APPROVED (2026-09-14)**. Namun audit pasca-09 + laporan user menemukan **gap lanjutan**:

- **Create/Update masih di modal** (`components.vue:159 NModal Editor Component`, `templates/index.vue:149 NModal Template Baru`, `administrations.vue:163 NModal Form Administrasi`, `master-data/create.vue` sudah halaman tetapi inconsistency dengan update via `master-data/[slug]/edit.vue` belum konsisten layout). User minta **semua create & update diarahkan ke halaman baru dengan layout yang sama** (detail: `AGENTS.md` PageShell + DataTable kanonis, `docs/design-system.md` PageShell + Modal Card). Ini butuh design route baru + breadcrumb + PageShell description + same toolbar.
- **Crash Tiptap** `Cannot read properties of undefined (reading 'configure')` muncul di `ComponentEditor.vue:40-69` saat create & delete. Root cause: `StarterKit` / `TiptapLink` / `TextAlign` / `TiptapTable` lazy import `default` bisa `undefined` bila ESM interop salah, lalu `.configure()` di `undefined` → crash. Plus `DocBinding/DocRepeater/DocCondition` custom nodes tidak guard. Delete path juga memicu re-render `ComponentEditor` tanpa `editor.destroy()` guard. Perlu **design error boundary + initialisation guard + extension audit** (referensi `https://tiptap.dev/docs/examples` — contoh `BubbleMenu`, `FloatingMenu`, `Placeholder`, `CharacterCount`).
- **Builder `/dashboard/templates/:id` masih minimal** (`templates/[id].vue:94 grid 260|1fr|320` sederhana, Block palette hanya `NButton` list, canvas tanpa EmptyStateCard, properties tanpa section header, warna `bg-[#f6f5f4]` belum dimanfaatkan). User minta **lebih cantik & mudah** — butuh polish visual (Notion-calm token + hairline + Level-1 shadow + pill CTA + illustration).
- **`DR-002` Administrasi Mapping incomplete — `missing: field`** (`server/dto/persuratan.dto.ts:DR-002` via `administrations.service:replaceSteps` cek `mapping_json` lengkap per `template.requirements`). UI saat ini `administrations.vue:178 NDynamicInput` dengan `mappingText` textarea JSON mentah (`'{"letter.number":...}'`) → user tidak tahu field apa yang missing, error `400 missing: letter.number` tidak terasosiasi ke field. Perlu **mapping editor per-template** (auto-generate rows dari `GET /api/doc-templates/:id/schema` atau `scanRequirements`) dengan inline error per-field.
- **Tiptap belum maksimal**: toolbar sekarang hanya 11 tombol teks (`B/I/U/H2/• List/...`) tanpa color/highlight/font-size, tanpa placeholder binding, tanpa table cell merge, tanpa highlight `item.*` invalid, tanpa slash-command. User minta **referensi `https://tiptap.dev/docs/examples`** dan toolbar layaknya office doc tetapi **very minimum** (1 baris, grouped, tidak membebani canvas).
- **Playwright video belum diaktifkan per-test**: `playwright.config.ts:21 video: 'retain-on-failure'` hanya saat fail, belum `video: 'on'` + `context` + `tracing`. User minta **rekam video untuk setiap pengujian** per `https://playwright.dev/docs/videos#record-video` (fitur `video`, `trace`, `screenshot`, `expect`).
- **Global UI/UX**: masih ada inkonsistensi spacing (`PageShell` body 24 vs form gap 12), font Inter tracking belum uniform, `NEmpty` CTA pill belum konsisten, `NAlert` warning vs error belum seragam, `prefers-reduced-motion` belum di-cover untuk Builder drag.

Posisi task: **FASE 1 UI-First polish** — tidak mengubah kontrak API/DB (9 EntitySchemas RBAC + `master_tables/columns` + `doc_*` + `mst_*` tetap), hanya **presentasi + routing + Tiptap hardening + test harness**. FASE 2 `11` akan implement tanpa redesign.

## Scope

### In Scope

- **Dedicated Create/Update pages** — wireframe + routes design: `/dashboard/components/create` & `/dashboard/components/:id/edit`, `/dashboard/templates/create` & `/dashboard/templates/:id/edit` (pecah dari `/dashboard/templates/:id` builder yang sekarang campur create+edit), `/dashboard/administrations/create` & `/dashboard/administrations/:id/edit`, `/dashboard/master-data/:slug/edit` refine, `/dashboard/documents/:slug/edit` bila ada — semua memakai **layout sama**: `PageShell` (title `20px Semibold tracking -0.125px Ink` + breadcrumb `<a href>` + description `12px #615d59` + actions slot) + `NForm` kanonis + footer `Batal | Simpan` pill + `NAlert` validation summary.
- **Tiptap `configure` crash hardening design** — audit `app/components/features/persuratan/ComponentEditor.vue:40-69` + `app/utils/tiptap-nodes.ts` + `server/services/tiptap-converter.service.ts` extension list vs `https://tiptap.dev/docs/examples`; design guard `if (!Ext || !Ext.configure)` fallback, `try/catch initEditor` → `NAlert error + retry`, `onBeforeUnmount editor.destroy` guard, `ClientOnly` + `fallback` slot, story variant `configureError`.
- **Builder `/dashboard/templates/:id` polish** — redesign 3-pane (`Library 260 | Canvas 1fr | Properties 320`) dengan token Notion (`#0075de/#0069c4/#005bab`, `#f6f5f4/#ffffff`, `#e6e6e6`, Inter, radius xs4/full, hairline + Level-1 shadow), `EmptyStateCard` di canvas, `NTree` searchable library, `PropertyPanel` section header eyebrow, `RepeaterEditor` pilih semua indeterminate, drag ghost + keyboard reorder, preview drawer 600px tabs.
- **Administrasi Mapping `DR-002` redesign** — ganti textarea JSON mentah menjadi **mapping editor terstruktur**: per `template_id` → fetch `schema`/requirements → render `NFormItem` per field (`target` `NSelect` master_data/manual/system + `name` + `view`) + inline error `missing: letter.number` → highlight field merah + `NAlert` summary + auto-scroll ke first error. - **Playwright video design** — spec `playwright.config.ts` `use: { video: 'on' }` (atau `'retain-on-failure'` + `trace: 'on-first-retry'`) + per-test `testInfo.attach` vs `video` artifact, `context` video size 1280×720, `mode` retain, `webServer` reuse, heading `HEADLESS=1` & `CI=true` handling.
