## Objective

Mengimplementasikan **FASE 2** dari `08-letter-builder-ux-improvement-ui-design` dengan fokus **memperbaiki bug `[DELETE] "/api/doc-components/:id": 409 Server Error` yang tampil sebagai *Server Error* generik** — seharusnya **409 Conflict + daftar referensi via modal `ReferenceList.vue`** (bukan 500) — serta **mengaudit & menyeragamkan semua error sejenis yang diperkenalkan di Task 05–07** (Master Data DDL, Document Engine, Template/Administrasi) agar konsisten dengan design `08`: **NAlert warning + ReferenceList (409)**, **inline validation + NAlert summary (400)**, **NEmpty+CTA (404/empty)**, **redirect 401 / single `AccessDeniedAlert` 403**, **NAlert+Coba lagi tanpa reset (500 PDF)**, **operasi div-by-zero → null+warning**, **image allowlist**, **version bump publish**, **slug/blacklist**, **status transition**, **PDF engine reuse**. Termasuk **wiring Prototype → halaman nyata** (`app/components/features/letter-builder/` + `app/pages/dashboard/...` + `app/stores/...` + `app/composables/...` + `stories/letter-builder/` regression), **library relevance** (Tiptap + Naive UI + Tailwind + `@vueuse/core` helper opsional), dan **Playwright test flow** `E2E-01..06` yang dirancang di FASE 1 agar executable `npm run test:e2e` HEADLESS=1.

## Scope

### In Scope

- **Backend hardening (audit 05–07)**:
  - Verifikasi & uniform `createError({ statusCode, message, data })` untuk semua 409 (`doc-components` create/update/delete, `doc-templates` create/update/delete, `master-data` create/delete + `syncColumns` 409, `administrations` create/update duplicate + `document_number` duplicate, `users/roles/guards/permissions` existing 409) — pastikan `data: { references, steps, administrations }` ter-serialisasi JSON dan tidak tertutup 500. Konsisten `statusCode ?? 500` di `server/api/**`.
  - Seragamkan 400 (`Zod`, slug blacklist `[a-z0-9_]`/`[a-z][a-z0-9-]{1,60}`, `config_json` discriminated 13 tipe, `TiptapDocSchema`, `DocNodeSchema`, `status transition`, `BR-003` item.* loop, `BR-002` requirement, `BR-003` orderable/searchable whitelist), 404 (`notFound`), 401/403 (`requireApiAccess`), 500 PDF (`generatePdfFromHtml` catch → `pdfError` + `status DRAFT` tanpa `pdfPath`).

  - Operasi-teks server recompute `ExpressionService.evalTextOperation` idempotence + div-by-zero → `null`+400 pesan, image allowlist (`https://`/`/api/storage/`/`data:image/`) reuse renderer, count tanpa join vs join (Task 06 fix dipertahankan), `master-operation` eval konsisten preview vs save.
- **Frontend wiring (referensi design FASE 1 `08`)**:
